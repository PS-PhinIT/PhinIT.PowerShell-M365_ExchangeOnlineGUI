# Screenshots

Ablage für Screenshots der **aktuellen** easyEXO-Oberfläche, die in der [README](../../README.md) verwendet werden.
Ältere Screenshots werden nicht aufbewahrt – sie bleiben bei Bedarf über die Git-Historie erreichbar.

## Konventionen

- **Dateiname ohne Versionsnummer:** `<Nr>_<bereich>.png` in Kleinbuchstaben, Nummer entsprechend der Reihenfolge in der
  Navigation (z. B. `01_dashboard.png`, `02_kalender.png`, `10_transportregeln.png`, `20_healthcheck.png`).
  Die Version, zu der ein Screenshot gehört, ergibt sich aus der README bzw. dem [CHANGELOG](../../CHANGELOG.md).
- Bei Änderungen an der Oberfläche den vorhandenen Screenshot **ersetzen** (gleicher Dateiname), nicht zusätzlich ablegen.
- Format PNG, Fenstergröße möglichst 1700 × 1000 (Standardgröße des Hauptfensters).
- Vor dem Einchecken **alle Mandanten-, Benutzer- und Domänennamen unkenntlich machen** (keine personenbezogenen Daten,
  keine Tenant-IDs).
