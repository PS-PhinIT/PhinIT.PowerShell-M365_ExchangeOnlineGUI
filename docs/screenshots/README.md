# Screenshots

Ablage für aktuelle Screenshots der easyEXO-Oberfläche, die in der [README](../../README.md) verwendet werden.

Konventionen:

- Dateiname: `easyEXO-<Version>_<Bereich>.png` (z. B. `easyEXO-0.1.2_Dashboard.png`)
- Vor dem Einchecken **alle Mandanten-, Benutzer- und Domänennamen unkenntlich machen**.
- Veraltete Screenshots beim Release einer neuen Version ersetzen, nicht zusätzlich ablegen.
